# Personal Portfolio Landing Page - CoderGirl

Uma landing page de portfólio pessoal moderna, elegante e totalmente responsiva desenvolvida com HTML5 e CSS3. O projeto apresenta uma estética premium em modo escuro (*Dark Mode*), combinando uma tipografia marcante, barra de navegação completa e uma seção hero com imagem de destaque integrada ao plano de fundo.

## Tecnologias Utilizadas

* HTML5: Estruturação semântica das seções (cabeçalho, navegação, seção principal e botões).
* CSS3: Estilização completa, gerenciamento de fontes, paleta de cores de alto contraste (preto, branco e vermelho) e posicionamento avançado.
* Flexbox: Alinhamento horizontal do cabeçalho e organização espacial dos links de navegação e botões de autenticação.

## Funcionalidades e Técnicas Aplicadas

* Cabeçalho de Navegação Completo: Barra superior que organiza de forma simétrica o logotipo "Portfolio.", os links institucionais (Home, About, Services, Contact) e os botões de ação secundários (Log In e Register).
* Seção Hero de Alto Impacto: Layout focado em apresentação pessoal com uma chamada principal robusta em caixa alta ("Hello, It's Me CoderGirl") e um texto descritivo alinhado.
* Botão de Chamada para Ação Destacado (CTA): Inclusão do botão "Hire Me" em branco puro e cantos suavizados, garantindo contraste imediato sobre o plano de fundo escuro para atrair cliques.
* Integração de Imagem de Fundo Imersiva: Uso de técnicas de posicionamento e opacidade em CSS para integrar uma fotografia de destaque na lateral direita, misturando-se suavemente com o fundo preto através de degradês ou máscaras.
